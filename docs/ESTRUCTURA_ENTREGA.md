# Estructura de Entrega

No se mueven paquetes ni imports. La organizacion de evidencia queda asi:

| Ruta | Uso |
|---|---|
| `backend/` | Monolito Django |
| `recomendation_service/` | Microservicio Flask |
| `frontend/` | Interfaz React |
| `nginx/` | API Gateway |
| `docs/` | Evidencia de rubrica y despliegue |
| `.env.example` | Variables para Docker/AWS |
